# 输出格式示例

## 力量训练记录
```
✅ 成功记录: 2024-03-24 | 卧推 | 80kg | 8次 | 4组
⏱️ 距离上一组间歇时间: 3分15秒
```

## 自重训练记录
```
✅ 成功记录: 2024-03-24 | 悬垂举腿 | 自重 | 12次 | 3组
```

## 距离+时长记录
```
✅ 成功记录: 2024-03-24 | 游泳 | 1.8km | 40min
✅ 成功记录: 2024-03-24 | 坡道走 | 2km | 30min | 坡度15%
```

## 带计时器的记录（组间歇提醒开启时）
```
✅ 成功记录: 2024-03-24 | 卧推 | 80kg | 8次 | 4组
⏱️ 距离上一组间歇时间: 3分15秒
⏰ 组间歇计时 2min 已启动
```

## 计时器提醒 + 下次记录
提醒行出现在最前面，因为 `check_alert()` 在脚本启动时执行。
```
⏰ 组间歇 2分 已到！（动作: 卧推）
✅ 成功记录: 2024-03-24 | 卧推 | 80kg | 6次 | 4组
⏱️ 距离上一组间歇时间: 2分05秒
⏰ 组间歇计时 2min 已启动
```

## 跨动作记录（不同动作间的间隔）
```
✅ 成功记录: 2024-03-24 | 深蹲 | 100kg | 8次 | 3组
⏱️ 距离上一个动作（卧推）间隔时间: 8分30秒
```

