# Fitness Tracker Skill

一个用于精准记录各类健身与运动数据的智能 Agent Skill，支持力量训练、自重训练、有氧运动等多种运动类型，并提供多日查询和两日对比分析功能。

## 主要特性

- **多运动类型支持**：覆盖力量训练（卧推、深蹲）、自重训练（引体向上、平板支撑）和有氧运动（跑步、游泳、骑行）。
- **灵活的单位换算**：支持 `kg/lbs`（重量）、`km/m`（距离）以及灵活的时长格式（如 `1h20min`, `90s`）。
- **数据追踪与分析**：
  - 生成单日或多日区间的健身报告。
  - 智能计算个人历史最佳记录（PR）。
  - 支持任意两日训练计划的对比。
- **内置组间歇计时器**：支持后台倒计时，并在训练间隙自动提醒。
- **本地化隐私存储**：数据完全使用本地 SQLite 数据库存储，支持跨会话持久化和自定义存储路径。

## 依赖要求

- Python 3.x（仅依赖标准库：`sqlite3`, `json`, `datetime`, `re`, `shutil` 等）
- 正常的文件系统读写权限（用于存放数据库和配置）
